Pixel Planet Generator 完整版

1. 双击 PixelPlanetGenerator-Full.exe，程序会使用系统当前默认浏览器打开界面。
2. 界面与网页版一致。点击保存后，单张图片由浏览器下载为 PNG，多张图片或动画下载为 ZIP。
3. locales 文件夹位于程序旁，可直接修改现有 JSON 文案。
4. 添加语言时，复制一个现有 JSON，使用语言代码命名（例如 ja-JP.json），修改 language.name 和其他文案。重新打开网页后，新语言会自动出现在右上角列表中。
5. 程序运行期间请勿移动或删除 _internal 或 web_app 文件夹。

本版本包含与网页版相同的静态生成、动画生成、自定义配色、比例控制、Seed 查询和角标边框按钮状态套图功能。
