Pixel Planet Generator 简易版

1. 双击 PixelPlanetGenerator-Simple.exe，程序会使用系统当前默认浏览器打开界面。
2. 点击保存后，单张图片由浏览器下载为 PNG，多张图片下载为 ZIP。
3. locales 文件夹位于程序旁，可直接修改现有 JSON 文案。
4. 添加语言时，复制一个现有 JSON，使用语言代码命名（例如 ja-JP.json），修改 language.name 和其他文案。重新打开网页后，新语言会自动出现在右上角列表中。
5. 程序运行期间请勿移动或删除 _internal 或 web_app 文件夹。

本版本使用与网页版一致的界面，但不包含动画和自定义配色。每种风格只能使用 0–49，共 50 个固定 Seed；其他比例、效果与角标状态套图功能保留。
